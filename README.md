#☕ Kulhad-Wali-Chai

An interactive, responsive landing page for a traditional "Kulhad Chai" stall. This beautifully designed website showcases the menu with prices, provides location and contact details, and includes a functional contact form—all built with pure HTML, CSS, and JavaScript.

## ✨ Key Features

*   **📱 Fully Responsive Design:**Looks great on desktops, tablets, and mobile devices.
*   **📋 Interactive Menu Catalog:** Showcases a variety of kulhad chai options with clear descriptions and pricing.
*   **📍 Business Information:** Easily findable location, opening hours, and contact details.
*   **📨 Functional Contact Form:** Allows customers to send messages directly from the website (form handling ready to be connected).
*   **✨ Pure Frontend:** Built with semantic HTML5, custom CSS3 (Flexbox & Grid), and vanilla JavaScript for lightweight performance.

## 🛠️ Tech Stack

This project is built using core web technologies without any external frameworks or libraries.

*   **HTML5** – For semantic and accessible structure.
*   **CSS3** – For custom styling, including Flexbox and CSS Grid layouts.
*   **JavaScript (ES6)** – For interactive features like form validation and DOM manipulation.

## 📁 Project Structure

The codebase is clean, organized, and easy to navigate.

## 🚀 How to Get Started

To run this project locally on your machine:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ekbiharii/Kulhad-Wali-Chai.git
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd Kulhad-Wali-Chai
    ```
3.  **Open the `index.html` file** in your favorite web browser. That's it! No server setup is required.
